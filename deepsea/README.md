# أغرب أسماك أعماق المحيطات — فيديو عمودي 9:16

فيديو قصير عمودي (1080×1920، 30fps، MP4/H.264 + AAC) عن أغرب أسماك أعماق المحيطات،
مع سرد صوتي عربي، نصوص عربية بتشكيل صحيح (libass)، موسيقى بيئة قاعية، ومؤثر Ken Burns.

## المخرج النهائي
- `strangest-deep-sea-fish-vertical.mp4` — المدة 1:17، 1080×1920 (9:16)

## محتوى الفيديو (8 مشاهد)
1. المقدمة — أغرب أسماك أعماق المحيطات
2. سمكة الصياد (Anglerfish)
3. سمكة البليب فيش (Blobfish)
4. أنقليس الجالبر (Gulper Eel)
5. سمكة الرأس الشفاف (Barreleye)
6. حبارة فامبير (Vampire Squid)
7. سمكة المجذاف (Oarfish)
8. الخاتمة ودعوة للمتابعة

## بنية المجلد
- `img0..img6*.png` — صور المشاهد (مولّدة)
- `audio/sc0..sc7.mp3` — مقاطع السرد الصوتي العربي
- `fonts/` — خطوط Noto Kufi/Naskh العربية
- `subs.ass` — ملف الترجمة العربية (يولّده build.py)
- `build.py` — سكربت البناء الكامل (ffmpeg)

## إعادة البناء
```
python3 build.py    # ينتج out.mp4 من الصور والصوت
```
يعتمد على حزمة `imageio-ffmpeg` (تحتوي ffmpeg بدعم libass/libfribidi).
