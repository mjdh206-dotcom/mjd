# محامص الحرمين — الإصدار الاحترافي 2.1

تطبيق عربي بالكامل (RTL) لمحل محامص مكسرات وضيافة وكاندي وقهوة: مبيعات وفواتير، مشتريات ومخزون،
زبائن وموردون بالعملتين، صندوق وإقفال، عمال ومسحوبات، طلبات مسبقة، تقارير ونسخ احتياطي —
**ويعمل دون إنترنت بالكامل**.

أُعيد بناء الواجهة بالكامل في 2.0 لتصبح احترافية لا شعبية: هوية **الإسبريسو والبراس**، خطّا **Cairo**
و**Amiri**، وضع فاتح وداكن، لوحة تحكم تنفيذية، رسوم بيانية، بحث شامل، وشاشة بيع سريعة تشبه أنظمة
نقاط البيع التجارية. ثم جاء **2.1** بكتالوج كامل للمكسرات والبزور، وبداية صفر، وتسعير سريع لكل صنف.

## 1. ما الجديد في 2.1

- **كتالوج 116 صنفاً** جاهزاً بكل أنواع المكسرات (لوز، جوز، كاجو، فستق، بندق، بيكان، مكداميا، صنوبر…) والبزور (دوّار الشمس، قرع، بطيخ، سمسم، حبة البركة، كتان، شيا، قنب، خشخاش…) والمجففات والقهوة والكاندي والضيافة.
- **بداية صفر**: كل الكميات والأسعار والأرصدة والفواتير تبدأ صفراً — لا بيانات تجريبية ولا أرقام وهمية. (يمكن تحميل بيانات تجريبية من الإعدادات عند الحاجة).
- **التسعير السريع**: شاشة واحدة لكل الأصناف مع حقول التكلفة/المفرق/الجملة، حساب الهامش فوراً، حفظ جماعي، تسعير بهامش ربح تلقائي، طباعة وتصدير قائمة الأسعار.
- **تعديل سعر أي صنف فوراً**: من جدول الأصناف، أو من شاشة البيع، أو من التسعير السريع.
- **الوحدة مرنة**: كيلوغرام أو قطعة أو علبة لكل صنف، وتحويل تلقائي داخل شاشة البيع (كغ/غرام/أوقية).
- **جرد شامل**: إدخال كميات كل الأصناف دفعة واحدة مع احتساب الفروقات.
- **تصفير مرن**: تصفير الحركات فقط، أو تصفير النظام بالكامل مع الاحتفاظ بالكتالوج والإعدادات والمستخدمين.

## 2. ركائز الإصدار 2.0

### هوية بصرية احترافية
- نظام تصميم كامل: إسبريسو `#241710` + براس `#C2983F` + كريمي `#F5F0E6`، مع ظلال وحدود وحالات دقيقة.
- خط **Cairo** للواجهة و**Amiri** للعناوين الكبيرة، أرقام جدولية، تباعد عربي مضبوط.
- شعار جديد (ختم البراس + حبة البن) وأيقونات تطبيق ولوجو وأيقونة تكيفية لأندرويد 8+.
- وضع داكن كامل لكل الشاشات، لا مجرد عكس ألوان.
- شريط جانبي داكن، شريط علوي زجاجي، بطاقات KPI، شرائح، Empty States، Skeleton-ready.

### لوحة التحكم
- ترحيب باسم المستخدم وتاريخ عربي، مبيعات اليوم بالليرة والدولار والمكافئ، مقارنة بالأمس.
- رسم حركة المبيعات، أفضل يوم، متوسط اليوم، صندوق اليوم، ذمم الزبائن، تنبيهات المخزون والصلاحية.
- أعلى 5 فواتير، متأخرات الزبائن، اختصارات سريعة، وتحديث سعر الصرف فوراً.

### نقاط البيع (شاشة البيع السريع)
- بحث فوري بالاسم/الباركود، تصنيفات، بطاقات أصناف مع المخزون والسعر.
- قارئ باركود يعمل كلوحة مفاتيح، وإدخال صوتي عربي (Google أو محرك الجهاز).
- اختيار الزبون مع اقتراح **آخر سعر بيع له**، ومستوى السعر (مفرق/جملة).
- تعديل كمية الوحدة، سعر البند، خصم بند أو فاتورة.
- تعليق الفواتير واستئنافها (Holds)، أزرار سريعة، حفظ بـ F2.
- دفع نقدي بتوليد الباقي، دين، أو جزئي، مع دفع بعملة مختلفة وتحويل تلقائي.
- **الربح يظهر للمدير فقط**، وواجهة العامل لا تحتوي التقارير ولا الأرباح.

### الفواتير
- فاتورة A5 أنيقة للطباعة/PDF، صورة عالية الدقة، مشاركة واتساب، QR للتحقق.
- طباعة حرارية بلوتوث **ESC/POS أصلية** مع اختيار الطابعة وتذكّرها.
- بحث الفواتير، فلترة بالفترة/العملة/الحالة، وتصدير Excel/CSV.
- عرض الفاتورة: بنود، مجاميع، ربح/هامش (مدير)، الخط الزمني (إنشاء/تعديل/إلغاء)، سبب الإلغاء.
- تعديل وإلغاء مع حفظ السجل وإرجاع المخزون — للمدير فقط.

### الأصناف والمخزون
- مكسرات، ضيافة، كاندي، قهوة، وسلال ضيافة مركّبة تخصم مكوّناتها.
- وحدات: كيلو/غرام/أوقية (قابلة للضبط)/قطعة/علبة، تحويل تلقائي.
- أسعار مفرق/جملة/تكلفة، باركود، صلاحية، حد أدنى.
- تنبيهات المخزون والصلاحية، جرد يدوي، سجل حركات.
- **تحويل التحميص**: خام ← محمّص، الفاقد ونسبته والتكلفة الفعلية للكيلو.

### الحسابات والعملات
- كل فاتورة بعملة واحدة، وسعر الصرف يُسجَّل داخلها ولا يتغيّر لاحقاً.
- أرصدة الزبائن والموردين **كل عملة على حدة** (لا خلط)، وكشوف حساب قابلة للطباعة/واتساب.
- دفعات، تصفية ديون، صندوق منفصل لكل عملة، إقفال يومي بفرق الصندوق.
- مشتريات ترفع المخزون وتحدّث **متوسط التكلفة**، ومسحوبات المحل، وعمال (الصافي = الراتب − السحوبات).

### التقارير والإدارة
- يومي/أسبوعي/شهري/فترة مخصصة، معروضة بالليرة أو الدولار أو مكافئ بعملة مختارة.
- مبيعات، مشتريات، مصاريف، مسحوبات، صافي الربح، هامش، متوسط فاتورة، أفضل الأصناف والزبائن.
- تصدير **Excel (CSV UTF-8)** و**PDF** (طباعة) بتصميم مُروَّس.
- مدير/عامل، سجل عمليات كامل، نسخ احتياطي واستعادة JSON، وبحث شامل `Ctrl+K`.

```

  MainActivity.kt           تحميل الحزمة من assets، طباعة حرارية، حفظ ملفات، صوت، رجوع
  assets/www/               حزمة الويب تُنسخ آلياً أثناء البناء
  res/                      أيقونات تكيفية + سبلاش + ثيم الإسبريسو

android/                    التطبيق الأصلي 1.0 (Kotlin + Compose + Room) — محفوظ كما هو
.github/workflows/
  build-apk-pro.yml         بناء نسخة الويب ثم APK الموقّع للنسخة 2.0
  build-apk.yml             بناء نسخة Kotlin الأصلية 1.0
```

**التخزين:** يعمل التطبيق محلياً بالكامل. بياناته محفوظة في `localStorage` داخل أصل آمن
(`appassets.androidplatform.net`) ويستمر عبر تحديثات التطبيق، مع نسخ احتياطي/استعادة.

**الجسور الأصلية:** حفظ الملفات في «التنزيلات»، طباعة HTML/PDF عبر نظام الطباعة، طباعة حرارية
بلوتوث ESC/POS، إدخال صوتي، اختيار ملف النسخة الاحتياطية، فتح واتساب والروابط، وزر الرجوع.

## 4. دقة الأرقام

- المبالغ تُخزَّن كأعداد صحيحة فقط: الليرة بوحدتها، والدولار بالسنت (×100).
- سعر الصرف مخزّن ×100، والكميات بالغرام/القطعة مع احتفاظ بـ3 منازل للمدخلات.
- لا Float في الحسابات المالية.
- منطق الحساب في `web-app/src/utils.js` و`web-app/src/store.js`، وفي نسخة Kotlin:
  `android/.../data/Calc.kt` و`util/Money.kt` مع اختبارات وحدة تُشغَّل في CI.

## 5. بناء APK

### النسخة 2.0 (WebView) — المستخدمة حالياً
`.github/workflows/build-apk-pro.yml`:

1. `npm ci && npm run build` داخل `web-app`.
2. نسخ `dist/` إلى `android-pro/app/src/main/assets/www`.
3. بناء `assembleRelease` وتوقيعه بمفتاح `android/app/keystore/haramayn.jks`.
4. نشر الناتج على فرع `build-artifacts` في `dist-pro/`:
   `mahamess-alharamayn-pro-2.1.0.apk` + `build.log`.

### النسخة 1.0 (Kotlin الأصلية)
`.github/workflows/build-apk.yml` — نفس المنطق لكن على `android/` وينشر في `dist/`.

### محلياً
```bash
cd web-app && npm ci && npm run build
cd ../android-pro
gradle :app:assembleRelease        # يتطلب JDK 17 + Android SDK 34
# الناتج: app/build/outputs/apk/release/app-release.apk
```

**مفتاح التوقيع:** `android/app/keystore/haramayn.jks` (كلمة السر `haramayn2026`، الاسم `haramayn`).
التوقيع بـv2/v3. احتفظ بالمفتاح: بدونه لا يمكن تثبيت تحديث فوق النسخة المثبّتة.

## 6. حالة الاختبار والتحقق

تم فعلياً في هذه الجلسة:

- ✅ **بناء إنتاجي** للواجهة: `vite build` بلا أخطاء (0 أخطاء oxlint).
- ✅ **اختبار آلي شامل** بـjsdom: دخول المدير/العامل، 17 شاشة، تسعير جماعي، تعديل سعر فوري،
  جرد شامل، تصفير كامل، إنشاء فاتورة وحفظها وفتحها، كشف حساب، شراء، تقارير، إعدادات، بحث — **0 أخطاء وقت تشغيل**.
- ✅ **بناء APK موقّع** عبر GitHub Actions، والتحقق من توقيعه (APK Signing Block) ومن تضمين
  حزمة الويب والأيقونات والجسور الأصلية داخله.
- ✅ **التحقق من الحزمة**: مطابقة بصمة ملفات JS/CSS داخل APK لمخرجات البناء النهائية.

ما **لم** يمكن تنفيذه في بيئة العمل:

- ❌ التجربة على جهازَي أندرويد حقيقيين (لا أجهزة/محاكي في البيئة).
- ❌ طباعة على طابعة حرارية بلوتوث فعلية، والتأكد من واتساب على جهاز حقيقي.

لذلك أُرفِق `TESTING.md` بخطوات فحص عملية (15–20 دقيقة) على جهازين قبل التسليم النهائي.

## 7. ملاحظات تشغيلية

- **البيانات محلية بالكامل** ولا يُرسل أي شيء إلى الإنترنت.
- **النسخ الاحتياطي**: تصدير JSON إلى «التنزيلات»، واستعادته بزر «استعادة» في الإعدادات.
- **الطباعة الحرارية**: اقترن بالطابعة من إعدادات البلوتوث أول مرة؛ يظهر لك التطبيق قائمة الأجهزة
  المقترنة ويحفظ اختيارك. الإيصال يُرسل كصورة نقطية 576/384 نقطة لضمان ظهور العربية.
- **الباركود**: قارئ USB/بلوتوث يعمل كلوحة مفاتيح — ركّز حقل البحث ثم امسح.
- **الصوت**: يستخدم محرك التعرف المثبّت على الجهاز؛ لا يعمل إن لم يوجد محرك عربي.
- **PDF**: من زر الطباعة اختر «حفظ كـ PDF» في نافذة النظام.
