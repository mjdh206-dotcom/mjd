# محمصة الدار — متجر وطلبات أندرويد

تطبيق أندرويد عربي RTL تجريبي لمحمصة مكسرات وقهوة وضيافة. يجمع واجهة الزبون ولوحة إدارة المتجر في تطبيق واحد كبداية عملية.

- تصفح المكسرات والقهوة والخلطات والكاندي والمقرمشات والبحث والتصنيف.
- سلة شراء، إدخال الاسم ورقم الهاتف، وإرسال طلب ومتابعة حالته.
- لوحة إدارة لمراجعة الطلبات وتغيير حالتها وإضافة المنتجات وتحرير الأسعار وإخفاء المتوفر.
- رفع صورة محلية للمنتج، وإعداد خصم يُحتسب فعلياً في السلة، وجمع عنوان التوصيل.
- واجهة عربية بخط Tajawal، هوية خضراء دافئة، وبيانات نموذجية قابلة للتعديل.

## تشغيل وبناء نسخة أندرويد

افتح مجلد `shuaa-remote` في Android Studio (JDK 17 وAndroid SDK 35)، أو نفّذ:

```bash
cd shuaa-remote
./gradlew assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظة مهمة قبل استقبال زبائن حقيقيين

هذه نسخة MVP لتجربة الواجهات وتدفق الطلب على **جهاز واحد**. البيانات تُحفظ محلياً؛ لذلك هاتف الزبون لا يرسل الطلب إلى هاتف صاحب المحل بعد. قبل البيع الفعلي يلزم خادم وقاعدة بيانات مشتركة، حساب آمن للمدير، تخزين صور مشترك، وإعداد التوصيل والدفع. العملة الابتدائية يورو وتحتاج تعديلها حسب بلد المحل. كما يلزم نشر APK على رابط عام ثابت قبل إنشاء QR صالح؛ لا يوجد رابط عام لهذه النسخة بعد.

## بنية المستودع

تطبيق Android Compose في `shuaa-remote/`، وسير عمل GitHub Actions يبني APK عند تحديثه.
