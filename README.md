# محامص الحرمين — تطبيق الزبائن

تطبيق Android عربي RTL لعرض منتجات محامص الحرمين وتجربة التسوق والطلب. هذه المرحلة مخصصة لتطبيق الزبون فقط؛ تطبيق إدارة المحل سيكون منفصلاً.

- تصفح المكسرات والقهوة والخلطات والكاندي والمقرمشات، مع بحث وتصنيفات وعروض تجريبية.
- سلة، بيانات الزبون وعنوان التوصيل، وسجل طلبات محلي.
- واجهة عربية بخط Tajawal وهوية خضراء دافئة.
- صفحة «عن التطبيق» تتضمن إهداء التطوير للمبرمج أمجد حبيب ورقم التواصل الذي زوّدتني به.

## تحميل نسخة الزبون التجريبية

[تحميل APK مباشر — محامص الحرمين](https://github.com/mjdh206-dotcom/mjd/raw/refs/heads/arena/4cd5a3f7-mjd/dist/al-haramain-customer-1.0.0.apk)

- ملصق A5 جاهز للطباعة، يتضمن QR للتنزيل: `dist/al-haramain-customer-qr-a5.pdf`
- ملفات QR PNG: `dist/al-haramain-customer-qr-poster.png` و`dist/al-haramain-customer-qr.png`

## بناء التطبيق

```bash
cd al-haramain-customer
./gradlew assembleDebug
```

ملف الناتج: `app/build/outputs/apk/debug/app-debug.apk` (Android 7.0 فأحدث).

## تنبيه مهم عن هذه المرحلة

هذه نسخة واجهات وتجربة فقط: الطلبات تُحفظ على هاتف الزبون ولا تصل للمحل بعد، ولا يصدر عنها إشعار أو رنين عند صاحب المحل. ذلك يحتاج تطبيق إدارة منفصلاً متصلاً بقاعدة بيانات/خدمة مشتركة، ثم تفعيل تنبيهات فورية على جهاز المحل. رقم المبرمج المعروض في صفحة «حسابي» هو اعتماد وتواصل فقط، وليس رقم استقبال الطلبات. العملة الحالية تجريبية باليورو وتحتاج ضبطاً قبل الإطلاق.
