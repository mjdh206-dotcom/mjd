# محامص الحرمين — تطبيق الزبون وتطبيق المتجر

تم فصل التطبيق إلى تطبيقين مستقلين بهويتين وحزمتين منفصلتين:

- **تطبيق الزبون:** استعراض المنتجات، الأقسام والعروض، السلة، عنوان التوصيل وسجل الطلبات.
- **تطبيق المتجر:** إدارة المنتجات والصور والأسعار والخصومات والتوفر، مراجعة الطلبات وتحديث حالتها، إعداد رقم المدير، وتجربة إشعار صوتي.
- العملة المعروضة في التطبيقين **الليرة السورية (ل.س)**. الأسعار التجريبية للتوضيح وليست قائمة أسعار محامص الحرمين.
- اعتمادية المبرمج أمجد حبيب ورقم التواصل +963988423100 ظاهرة في التطبيقين.

## البناء

كل تطبيق مشروع Android مستقل، ويتوفر ملف APK تجريبي في مجلد `dist/` عند نجاح GitHub Actions.

```bash
cd al-haramain-customer && ./gradlew assembleDebug
cd ../al-haramain-store && ./gradlew assembleDebug
```

## تنبيه قبل استقبال زبائن حقيقيين

التطبيقان منفصلان الآن، لكنهما **غير موصولين بخادم مشترك بعد**: بيانات المنتجات التي يعدلها تطبيق المتجر لا تنتقل تلقائياً إلى هاتف الزبون، والطلب الذي ينشئه الزبون لا يصل حالياً إلى شاشة الطلبات في تطبيق المتجر. شاشة المتجر تحفظ بيانات محلية، ورقم المدير يُخزّن على جهاز المحل، كما أن زر تجربة الإشعار يختبر صوت الهاتف فقط. حتى يصل الطلب الحقيقي ويرن جهاز المتجر فوراً، يلزم إعداد قاعدة بيانات/API مشتركة وإشعارات Push (مثل Firebase)، ثم إدخال بيانات مشروع الخدمة. رقم المبرمج ليس رقم استقبال الطلبات.
