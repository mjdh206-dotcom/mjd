# أسرار المحيطات — ريل عمودي ١٢ ثانية 🌊

فيديو قصير احترافي عامودي (9:16) مع **تعليق صوتي عربي** و**مؤثرات صوتية مصمّمة خصيصاً** — **بدون أي موسيقى**.

## الملف النهائي

| البند | القيمة |
|---|---|
| الملف | `ocean_secrets_reel.mp4` |
| الأبعاد | 1080×1920 (عمودي 9:16) |
| المدة | 12.00 ثانية بالضبط |
| الفيديو | H.264 High، 30fps، CRF 14–16 |
| الصوت | AAC 192 kbps، ستيريو 48 kHz |
| المعايرة | -14 LUFS (معيار المنصات الاجتماعية) |
| الحجم | ~10.8 ميجابايت |

## النص التعليقي (عربي فصحى)

| التوقيت | الجملة |
|---|---|
| 0.35 – 5.08 ث | في أعماق المحيط يختبئ عالم لم يره أحد. |
| 5.38 – 8.59 ث | أسرار دُفنت منذ ملايين السنين. |
| 8.89 – 12.0 ث | ثمانون بالمئة منه لم تُكتشف بعد. |

النص المكتوب على الشاشة يظهر ويتلاشى متزامناً مع التعليق الصوتي.

## بنية المشاهد

| الزمن | المشهد | الحركة |
|---|---|---|
| 0.0 – 2.9 ث | أشعة الشمس من عمق المحيط | زووم داخل + بان للأعلى |
| 2.9 – 5.5 ث | قنديل بحر مضيء | زووم للخارج |
| 5.5 – 8.3 ث | الحبار العملاق في الظلام | زووم داخل + بان يسار |
| 8.3 – 12.0 ث | فتحات حرارية (Black Smokers) | زووم داخل + بان للأعلى |

بين المشاهد: تلاشٍ متقاطع (Cross Dissolve) 0.7 ث، مع طبقة "ثلج بحري" (جسيمات مائية) متحركة، وتدرّج لوني سينمائي (Teal).

## التصميم الصوتي (مؤثرات فقط — لا موسيقى)

* **محيط مستمر**: ضجيج بنّي مُرشَّح + هسهسة تيار خفيفة + درون ضغط منخفض (تتحرك شدته ببطء).
* **دوبلر/دقات انتقال**: ضربة باس عميقة عند كل قطع.
* **هواش مائي** (Whoosh) قبل كل انتقال.
* **مطرقة سونار** مع صدى عند 4.35 ث.
* **فقاعات** متقطعة في الخلفية.
* **رِيسر تصاعدي** قبل الانتقال إلى المشهد الأخير.
* **ضربة ختامية** عند بدء تلاشي النهاية.
* **Ducking** تلقائي للخلفية تحت التعليق الصوتي (Sidechain Compressor) ليبقى الكلام واضحاً.

> كل المؤثرات مُولَّدة رقمياً بالكود (لا ملفات جاهزة) — انظر `build/make_assets.py`.

## إعادة البناء

```bash
# 1) توليد الأصول: النصوص العربية، الجسيمات، والمؤثرات الصوتية
python3 build/make_assets.py

# 2) تركيب الفيديو الكامل (مشاهد + نصوص + صوت)
python3 build/build_video.py
```

يتطلب: `ffmpeg` (متوفر عبر `imageio-ffmpeg`)، و`numpy`، `pillow`، `arabic-reshaper`، `python-bidi`.

## ملاحظة تقنية

مكتبة Pillow في هذه البيئة مبنية **بدون** محرك تشكيل النصوص (raqm/HarfBuzz)، لذلك تُرسم النصوص العربية عبر
`arabic_reshaper` + `python-bidi` مع الاعتماد على صور الحروف المتصلة (Presentation Forms-B).
الخطوط المستخدمة تدعم هذه الصور بالكامل: **Noto Kufi Arabic** (العنوان) و**IBM Plex Sans Arabic** (النصوص).

## التحميل

أسهل طريقة: شغّل صفحة التحميل ثم اضغط الزر:

```bash
python3 download/serve.py 8000      # ثم افتح http://localhost:8000
```

الصفحة تحتوي مشغّل فيديو + زر تحميل للنسخة الكاملة (1080p) وزر للنسخة الخفيفة (720p)،
وخادم `serve.py` يدعم طلبات `Range` ليعمل البث والتحميل على كل المتصفحات (بما فيها آيفون).

| الملف | الأبعاد | الحجم |
|---|---|---|
| `ocean_secrets_reel.mp4` | 1080×1920 | 10.7 ميجابايت |
| `ocean_secrets_reel_720p.mp4` | 720×1280 | 2.2 ميجابايت |
