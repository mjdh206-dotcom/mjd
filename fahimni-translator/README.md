# فَهِّمني — مترجم الحكي الفوري المبسط (2.0) 🎙️

> **تم تطوير وتنفيذ هذا التطبيق بواسطة.امجد حبيب**

شاشة واحدة فائقة البساطة والسرعة **بزرّين اثنين فقط** بدون أي قوائم معقدة:

1. **🎯 الزر الأزرق («اعرف شو لغتو وترجم للعربي»):**
   اكبسه ودع الشخص الذي أمامك يتكلم — يكتشف التطبيق لغته تلقائياً ويترجم كلامه للعربي وينطقه بالصوت فوراً.
2. **🎙️ الزر الأخضر («احكي بالعربي — يترجملو للغتو»):**
   اكبسه وتكلم بالعربي بأي لهجة — يترجم كلامك مباشرةً إلى لغة الشخص التي اكتشفها التطبيق وينطقها له بالصوت!
