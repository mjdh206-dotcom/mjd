# فَهِّمني — مترجم الحكي واللهجات الذكي 🎙️🌍

> **تم تطوير وتنفيذ هذا التطبيق بواسطة.امجد حبيب**

تطبيق أندرويد عربي ذكي وفائق السرعة يعمل عبر الإنترنت لتسهيل ترجمة الكلام المحكي (الحكي) بين جميع اللهجات العربية واللغات العالمية بالصوت الفوري.

## أبرز المميزات المنفّذة

- **🎯 كشف تلقائي ذكي للهجة المتحدث**: يكتشف تلقائياً لهجة الشخص الذي أمامك (١٣ لهجة عربية: شامية سورية، لبنانية، أردنية/فلسطينية، مصرية، خليجية/سعودية، عراقية، مغربية دارجة، جزائرية، تونسية، ليبية، يمنية، سودانية، وعربية مبسطة + ١٢ لغة عالمية) مع عرض نسبة الثقة.
- **🎙️ ترجمة صوتية ثنائية الاتجاه وجهاً لوجه**:
  - **احكي بلهجتك**: تكلم بأي لهجة عربية بحرية، وسيفهمك الطرف المقابل بالصوت فوراً بلهجته أو بالعربية المبسطة الواضحة.
  - **اسمع المقابل**: استمع لكلام الشخص الذي أمامك، فيكتشف التطبيق لهجته تلقائياً وينطق لك معناها بلهجتك بالصوت المباشر.
- **🔄 وضع الطاولة وجهاً لوجه (180°)**: يقسم الشاشة ويقلب النصف العلوي للشخص الجالس أمامك لسهولة المحادثة المباشرة.
- **🔁 وضع الحوار التلقائي المستمر بدون لمس**: يتناوب الاستماع والنطق تلقائياً بين الطرفين.
- **💡 مفسّر الكلمات الشعبية الصعبة**: يشرح تلقائياً المفردات العامية الصعبة في الجملة (مثل: *دابا = الآن*، *بزاف = كثيراً*، *شكو ماكو = ما الأخبار*، *هسة = الآن*).
- **🌍 استوديو «جملتك بكل اللهجات»**: شاهد واسمع جملتك محوّلة إلى ١٠ لهجات عربية دفعة واحدة.
- **📚 دفتر عبارات صوتية سريعة**: عبارات جاهزة للسوق، المواصلات، المطاعم، العمل، والطوارئ تُترجم وتُنطق بضغطة واحدة.
- **📲 تكامل مع واتساب والنظام**: حدد أي نص في هاتفك أو شاركه إلى **فَهِّمني** لترجمة لهجته ونطقه فوراً.
