# حارس الشبكة (Haris Wi-Fi 2.0) — كاشف المتصلين والكاميرات وقاطع الاتصال

> **✨ تمت برمجة هذا التطبيق بواسطة Amjad omega ✨**

تطبيق أندرويد عربي بالكامل (RTL)، سهل جداً وبسيط، يتيح لك:
1. **معرفة جميع المتصلين بشبكة الواي فاي + كشف كاميرات المراقبة اللاسلكية** (Hikvision, Dahua, EZVIZ, Imou, ICSee/XMeye, V380, Tapo, Tuya, ONVIF/RTSP) في ثوانٍ.
2. **قطع الاتصال وإيقاف بث الكاميرات بضغطة زر واحدة**:
   - **إغراق جلسات البث والشبكة (12 خط متوازٍ RTSP / ONVIF / TCP RST / UDP QUIC)** لإسقاط جلسات البث والكاميرات فوراً.
   - **قطع كامل عبر الروت (`su -c`)** عبر `arping` (ARP Spoofing) + `iptables` + تعطيل `ip_forward`.
   - **قفل وحظر فعلي نهائي من الراوتر (مضمون ١٠٠٪ بدون روت)** عبر لوحة الراوتر الأوتوماتيكية المدمجة التي تسجل الدخول وتبحث عن عنوان الـ MAC وتحظره بضغطة واحدة.
3. **تسمية أجهزة العائلة** وتمييزها كأجهزة موثوقة.
