# حارس الشبكة (Haris Wi-Fi) — كاشف المتصلين وفصل الاتصال بضغطة واحدة

تطبيق أندرويد عربي بالكامل (RTL)، سهل جداً وبسيط، يتيح لك:
1. **معرفة جميع المتصلين بشبكة الواي فاي** في ثوانٍ (الاسم، الماركة، نوع الجهاز، عنوان IP، عنوان MAC، وسرعة الاستجابة).
2. **فصل الاتصال عن أي جهاز بضغطة زر واحدة** («فصل الاتصال فوراً ✂️» أو «فصل كل الغرباء بضغطة واحدة»).
3. **حظر المتطفلين نهائياً من الراوتر** عبر لوحة الراوتر الذكية المدمجة التي تنسخ عنوان الـ MAC وتملأ بيانات الدخول تلقائياً.
4. **تسمية أجهزة العائلة** (مثل: «جوال أبي»، «تلفزيون الصالة»، «لابتوب العمل») وتمييزها كأجهزة موثوقة.

## تحميل ملف APK الجاهز للتثبيت

ملف APK موقّع وجاهز للتثبيت مباشرة على أي هاتف أندرويد (أندرويد 7.0 فأعلى):

```
dist/haris-wifi-1.0.0-debug.apk
```

## المزايا الرئيسية

- **فحص شامل وسريع (48 خيط فحص متوازٍ)**: يفحص النطاق الفرعي بالكامل (`1..254`) عبر ICMP + منافذ TCP الشائعة للهواتف والشاشات + نبضات UDP + جدول الـ ARP.
- **فصل الاتصال بـ ٣ مستويات**:
  - **فصل فوري بضغطة واحدة** (يدعم الفصل الكامل عبر `iptables / ip neigh` للأجهزة ذات الروت، وإرباك الجلسة المباشر للأجهزة بدون روت).
  - **فصل مؤقت بوقت محدد** (١٥ دقيقة أو ساعة كاملة — مثالي لإيقاف الإنترنت عن أجهزة الأطفال وقت الدراسة أو النوم).
  - **لوحة حظر الراوتر الذكية المدمجة** (تفتح بوابة الراوتر `192.168.1.1` وغيرها داخل التطبيق مع زر تعبئة الدخول تلقائياً وزر لصق الماك مباشرة في خانة الحظر).
- **بلاطة في الإعدادات السريعة (Quick Settings Tile)** لفتح «حارس الشبكة» من شريط الإشعارات في أي وقت.

## البناء محلياً أو عبر GitHub Actions

```bash
cd haris-wifi

```
