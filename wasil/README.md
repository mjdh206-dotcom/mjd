# واصل — رقم أمريكي لاستقبال رسائل التفعيل

تطبيق أندرويد عربي بسيط يعرض رسائل SMS الواردة إلى **رقم أمريكي تملكه أنت**، مع تمييز تلقائي
لأكواد التفعيل (واتساب، فايبر، Google…) وزر نسخ بضغطة واحدة، وواجهة عربية RTL داكنة بخط Tajawal.

## الحقيقة أولاً — اقرأ هذا قبل أي شيء

- **لا يوجد تطبيق في العالم يولّد رقم هاتف حقيقي بنفسه.** الأرقام الحقيقية تمنحها شركات اتصالات
  ومزوّدو خدمة مرخّصون (Twilio، Telnyx، Google Voice…). أي تطبيق يدّعي العكس يمنحك رقماً مشتركاً
  مع الغير أو خدمة وسيطة عرضة للحظر.
- «واصل» إذن **صندوق وارد منظّم وآمن لرقم اشتريته بحسابك الخاص**: المزوّد يستقبل الرسالة،
  خادمك الصغير يلتقطها عبر webhook، والتطبيق يعرضها على هاتفك. كل المنظومة باسمك وعلى بنيتك.
- **تنبيه واتساب وفايبر:** أغلب أرقام خدمات الإنترنت (VoIP) — ومنها أرقام Twilio — قد يرفضها
  واتساب أو فايبر عند التفعيل، أو يقبلها ثم يحظر الحساب لاحقاً، لأن شروط استخدامهما تفضّل أرقام
  الهواتف المحمولة العادية. **النجاح غير مضمون.** أوفر الخيارات حظاً للأفراد هو **Google Voice**
  (رقم أمريكي حقيقي مجاني تقريباً، لكنه بلا API رسمي ويُستخدم عبر تطبيقه)، بينما يقدّم **Twilio**
  أفضل تجربة برمجية يعمل عليها هذا المشروع. جرّب رقماً واحداً قبل شراء رصيد كبير.
- الطريقة مسموحة قانونياً: رقمك أنت، حسابك أنت، خادمك أنت، وكود مفتوح المصدر. يبقى التزامك
  بشروط واتساب وفايبر مسؤوليتك عند استخدامه لتفعيل حساباتهما.

## كيف تعمل المنظومة؟

```
 واتساب/فايبر ──SMS──► رقمك الأمريكي (Twilio)
                              │ webhook HTTP POST
                              ▼
                    خادمك الصغير (Node/Express)  ──HTTPS + Bearer──►  تطبيق واصل على هاتفك
```

## وضعان للتشغيل

1. **وضع المعاينة**: يعمل فور التثبيت برسائل تجريبية لاستعراض كل الشاشات بدون خادم ولا إنترنت.
2. **الوضع الحقيقي**: تدخل رابط خادمك والرمز السري، فيجلب التطبيق الرقم والرسائل، ويزامن تلقائياً
   كل 15 ثانية أثناء الفتح وكل 15 دقيقة في الخلفية (WorkManager) مع إشعارات محلية للرسائل الجديدة.

## خطوات التشغيل الحقيقي (ثلاث مراحل)

1. **المزوّد:** أنشئ حساب [Twilio](https://www.twilio.com) واشترِ رقماً أمريكياً قادراً على SMS.
2. **الخادم:** انشر مجلد [`backend/`](backend/README.md) (شرح كامل بالداخل) واربط فيه webhook الرقم،
   ثم عيّن `API_TOKEN` و`US_NUMBER`.
3. **التطبيق:** ثبّت واصل، اختر «الوضع الحقيقي»، الصق رابط الخادم والرمز السري، واضغط «اختبار الاتصال».

## المزايا

- واجهة عربية RTL كاملة، تصميم داكن فخم (أسود + ذهبي) بخط Tajawal.
- كشف تلقائي لكود التفعيل من نص الرسالة (عربي/إنجليزي) مع زر نسخ فوري.
- بطاقة الرقم الأمريكي مع نسخ سريع وشارة حالة الاتصال ووقت آخر مزامنة.
- مزامنة دورية في الواجهة والخلفية + إشعارات محلية (تُطلب مرة واحدة على أندرويد 13+).
- تخزين محلي لآخر الرسائل لعرضها فور الفتح، ومسحها بضغطة.
- لا يجمع أي بيانات، لا إعلانات، لا حسابات، ولا أي طرف ثالث غير خادمك أنت.

## المتطلبات

- هاتف أندرويد 7.0 فأعلى (minSdk 24).
- للوضع الحقيقي: خادم عام بـ HTTPS (انظر دليل النشر في `backend/README.md`).

## تحميل جاهز

بعد نجاح البناء التلقائي يُحفظ ملف APK موقّعاً للتثبيت المباشر في:

```
dist/wasil-1.0.0-debug.apk
```

ثبّته على الهاتف واسمح بـ«تثبيت من مصادر غير معروفة» عند الطلب. أول تشغيل يفتح شاشة الإعداد،
ويمكنك الاكتفاء بوضع المعاينة لاستعراض كل شيء فوراً.

## البناء

```bash
cd wasil
./gradlew assembleDebug
# الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
```

أو افتح مجلد `wasil` في Android Studio (AGP 8.7 / Kotlin 2.0 / JDK 17).

### بناء تلقائي على GitHub

كل دفعة إلى `wasil/` تشغّل سير عمل **Build واصل APK** وتنتج ملف APK قابلاً للتنزيل من
تبويب Actions → آخر تشغيل → Artifacts.

## بنية المشروع

```
wasil/
├── backend/                  # خادم Node/Express (webhook + API محمي)
│   ├── server.js
│   ├── package.json
│   └── .env.example
└── app/src/main/java/com/wasil/app/
    ├── MainActivity.kt       # التنقل وطلب إذن الإشعارات وجدولة المزامنة
    ├── WasilViewModel.kt     # الحالة والمزامنة الدورية
    ├── data/                 # النماذج، التخزين المحلي، عميل الشبكة، كاشف الكود
    ├── work/                 # عامل WorkManager للمزامنة الخلفية
    ├── notify/               # الإشعارات المحلية
    └── ui/                   # الشاشات والمكوّنات والثيم العربي
```

## الخصوصية

الرسائل تُخزّن على خادمك أنت (ملف JSON محلي) وتُنقل عبر اتصال HTTPS محمياً برمز Bearer،
ثم تُحفظ نسخة منها على هاتفك فقط. لا يمر أي شيء عبر مطوّر التطبيق، ولا توجد أي خدمات تحليلات.
