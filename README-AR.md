# 🎬 مصنع الفيديو - دليل الاستخدام

## كيف تفتح التطبيق على جوالك

### الطريقة الأولى: تنزيل من المحادثة

1. ارجع للمحادثة في Arena
2. ابحث عن ملف `videoforge-app.html`
3. اضغط عليه لتنزيله
4. افتحه بالمتصفح على جوالك

---

### الطريقة الثانية: نسخ المحتوى يدوياً

1. انسخ محتوى ملف `videoforge-app.html`
2. افتح تطبيق ملاحظات على جوالك
3. الصق المحتوى
4. احفظ الملف باسم `app.html`
5. افتحه بالمتصفح

---

### الطريقة الثالثة: من الكمبيوتر

1. افتح المحادثة على الكمبيوتر
2. نزل الملف
3. ابعت الملف لجوالك عبر واتساب/تيليجرام
4. افتحه بالمتصفح
