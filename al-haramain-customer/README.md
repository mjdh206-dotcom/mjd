# محامص الحرمين — تطبيق الزبائن

تطبيق Android عربي للتصفح والسلة وإدخال بيانات التوصيل وعرض سجل الطلبات. هذا التطبيق منفصل عن تطبيق الإدارة الذي سنبنيه في المرحلة التالية.

## النسخة الحالية

- متجر الزبائن: مكسرات، قهوة، خلطات، كاندي ومقرمشات، بحث وأقسام وعروض نموذجية.
- سلة وبيانات الزبون وعنوان التوصيل وسجل محلي للطلبات.
- صفحة تعريف باسم محامص الحرمين واعتماد: «تم تطوير هذا البرنامج بواسطة المبرمج أمجد حبيب» ورقم +963988423100.
- بناء Debug APK عبر `./gradlew assembleDebug` باستخدام JDK 17 وAndroid SDK 35.

## قبل إطلاق استقبال الطلبات

الطلبات في النسخة الحالية لا تغادر جهاز الزبون ولا ترسل إشعاراً لصاحب المحل. المرحلة التالية هي بناء تطبيق الإدارة وتوصيل التطبيقين بواجهة API وقاعدة بيانات مشتركة؛ داخل تطبيق الإدارة يضيف صاحب المحل رقم المدير ورقم استقبال الطلبات. بعدها نفعّل إشعاراً فورياً وصوت تنبيه على جهاز المحل. لا يُستخدم رقم المبرمج الموجود في صفحة الاعتماد كرقم للمحل.

بيانات المنتجات والأسعار والعروض الحالية نموذجية، والعملة الافتراضية يورو. يجب إدخال بيانات المحل الفعلية والعملة والتوصيل قبل نشر تجاري.
