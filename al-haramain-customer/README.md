# محامص الحرمين — تطبيق الزبون

تطبيق Android عربي مستقل للزبائن. يحتوي على منتجات تجريبية، أقسام وبحث وعروض وسلة، وإدخال الاسم والهاتف وعنوان التوصيل وحفظ سجل الطلبات.

- العملة: الليرة السورية (ل.س)، والأسعار الظاهرة مجرد أمثلة قابلة للتعديل لاحقاً.
- يتضمن صفحة اعتماد المبرمج أمجد حبيب ورقم +963988423100.
- بناء Debug APK: `./gradlew assembleDebug` (JDK 17 وAndroid SDK 35).

**حالياً:** الطلبات تبقى على جهاز الزبون ولا تصل لتطبيق المتجر؛ يلزم Backend مشترك وPush Notifications قبل الإطلاق التجاري. تطبيق المتجر مشروع منفصل في `../al-haramain-store`.
