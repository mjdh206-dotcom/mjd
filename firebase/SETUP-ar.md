# تفعيل Firebase — محامص الحرمين

التطبيقان يحتويان الآن على ربط Firebase للمشروع `al-haramain-roasters`، لكن **الخدمات السحابية لا تعمل فعلياً قبل تنفيذ خطوات النشر أدناه**. لا تضع ملف Service Account أو كلمة مرور في Git أو داخل APK.

## 1) إعداد Firebase Console

1. افتح مشروع `al-haramain-roasters` في Firebase Console.
2. من **Authentication → Sign-in method** فعّل:
   - Anonymous للزبائن.
   - Email/Password لمدير المتجر.
3. من **Authentication → Users** أنشئ مستخدم المدير ببريد وكلمة مرور قوية، ثم احتفظ بمعرّف UID الظاهر للمستخدم.
4. أنشئ Firestore Database في وضع الإنتاج، واختر منطقة مناسبة قريبة من العملاء. انشر قواعد `firebase/firestore.rules` قبل استقبال الطلبات.
5. في Firestore أنشئ مستنداً واحداً:
   - المسار: `config/access`
   - الحقل `adminUid` من النوع string، وقيمته UID المدير الذي أنشأته.
6. من إعدادات Cloud Messaging تأكد أن Firebase Cloud Messaging مفعّل. اسم قناة التنبيه في تطبيق المتجر هو `haramain_orders`.

## 2) نشر القواعد والتنبيه

من جذر المستودع، سجّل دخول Firebase CLI بحساب يملك المشروع، ثم انشر القواعد والوظيفة:

```bash
npm install --global firebase-tools
firebase login
firebase use al-haramain-roasters
firebase deploy --only firestore:rules,functions
```

وظيفة الإشعار تستخدم Cloud Functions الجيل الثاني في `europe-west1`. قد يطلب Firebase ترقية المشروع إلى خطة **Blaze** وربط وسيلة فوترة لنشر الوظائف. لن يعمل تنبيه FCM البعيد قبل نجاح نشر الوظيفة، كما يجب السماح بإشعارات تطبيق المتجر وتفعيل صوت قناة الإشعار من إعدادات Android.

## 3) إنشاء APKs وتثبيتها

بعد نشر backend، ابنِ التطبيقين من GitHub Actions (أو Gradle محلياً) وثبّت النسختين. يجب فتح تطبيق المتجر، تسجيل الدخول بحساب المدير، ثم السماح بالإشعارات. سيُنشئ المتجر المنتجات التجريبية في Firestore عند أول دخول إذا كانت مجموعة المنتجات فارغة؛ الأسعار هناك أمثلة ويجب تعديلها قبل الاستخدام الحقيقي. تُرسل طلبات العميل إلى Firestore، ويحسب الخادم الأسعار مجدداً من كتالوج المتجر. أي طلب لا يمكن التحقق منه يوضع بحالة «مراجعة يدوية» وينبه المتجر.

## ملاحظات أمنية وتشغيلية

- قواعد Firestore تمنع قراءة الطلبات إلا للمدير والزبون صاحب الطلب، وتمنع الكتابة في المنتجات والعروض إلا لـ UID المدير المحدد في `config/access`.
- تنبيه FCM لا يحتوي اسم الزبون أو رقم هاتفه أو عنوانه؛ تفاصيل الطلب لا تظهر إلا بعد دخول المدير.
- إشعار Android يعتمد على إذن POST_NOTIFICATIONS وإعدادات القناة التي يسيطر عليها المستخدم والجهاز؛ لا يمكن للتطبيق تجاوز وضع الصامت أو «عدم الإزعاج».
- صور المنتجات المختارة محلياً في تطبيق المتجر لا تُرفع إلى Firebase Storage حالياً؛ المزامنة المشتركة تشمل الاسم والقسم والسعر والوحدة والخصم والتوفر والوصف والرمز التعبيري.
- رقم المدير إعداد محلي حالياً ولا يُستخدم كرقم عام لاستقبال الطلبات. رقم المبرمج `+963988423100` ليس رقم استقبال الطلبات.
- لم يتم نشر القواعد أو الوظائف من بيئة التطوير، ولم يُختبر إرسال FCM فعلياً حتى الآن.
