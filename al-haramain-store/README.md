# محامص الحرمين — تطبيق المتجر

تطبيق Android منفصل لصاحب المحل لإدارة كتالوج محامص الحرمين والطلبات.

- إضافة وتحرير المنتجات وصورها وأسعارها بالليرة السورية (ل.س) ونسب الخصم والتوفر.
- شاشة ملخص الطلبات وقائمة لإدارة الحالة.
- إعداد رقم مدير الاستقبال، اختبار إشعار الهاتف وصوته، تشغيل/إيقاف صوت التنبيه.
- صفحة اعتماد المبرمج أمجد حبيب ورقم +963988423100.
- بناء Debug APK: `./gradlew assembleDebug` (JDK 17 وAndroid SDK 35).

**الربط الحقيقي لم يُفعّل بعد:** المنتجات والإعدادات والطلبات المحلية محفوظة على جهاز الإدارة. لإظهار تعديلات الكتالوج عند الزبون واستقبال طلباته وإصدار Push Notification تلقائي، يلزم إعداد API وقاعدة بيانات مشتركة وإعداد مشروع إشعارات (مثل Firebase). زر التجربة يختبر إشعار الهاتف فقط، ولا يعني وصول طلب زبون.
