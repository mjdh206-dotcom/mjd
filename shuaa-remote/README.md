# شُعاع — ريموت الشاشات القديمة

تطبيق أندرويد عربي كامل يحوّل الهاتف إلى جهاز تحكم للشاشات والتلفزيونات القديمة (CRT) والحديثة،
عبر مُرسِل الأشعة تحت الحمراء المدمج في الهاتف.

> **بمجرد توجيه الهاتف نحو الشاشة** يبدأ التطبيق بمسح المشهد وتحديد حدود الشاشة، ثم يختار الريموت
> المناسب من مكتبة مدمجة، ويجرّب أكواد التشغيل تلقائياً حتى تعمل الشاشة — بضغطتين فقط.

## المزايا

- **مكتبة أكواد ضخمة ومدمجة**: ١٠٤ ماركة و١٩٢ مجموعة أكواد (سامسونج، إل جي، سوني، توشيبا، شارب،
  فيليبس، باناسونيك، تي سي إل، هايسنس، دايوو، هيتاشي، جي في سي…). تعمل **بدون إنترنت**.
- **مطابقة تلقائية ذكية**: يرسل كود الطاقة لكل مجموعة أكواد للماركة، والمستخدم يؤكد «أضاءت» أو «التالي».
- **مسح الشاشة بالكاميرا**: تحليل محلي لإطار الكاميرا (إضاءة/تباين/نسبة الأبعاد) للتحقق من وجود شاشة،
  مع إطار مسح متحرك وتلميحات فورية. لا تُحفظ أي صورة ولا يُرسل شيء إلى الإنترنت.
- **ريموت كامل احترافي**: الطاقة، المصدر، كتم الصوت، لوحة أسهم + OK، الصوت/القناة مع تكرار تلقائي
  عند الاستمرار بالضغط، رجوع/قائمة/رئيسية/خروج، لوحة أرقام، أزرار وسائط، أزرار ملوّنة، وأزرار إضافية.
- **أجهزة متعددة**: احفظ كل شاشة باسمها، عيّن الريموت الافتراضي، وأعد التسمية أو الحذف.
- **بلاطة في الإعدادات السريعة** لفتح الريموت من أي شاشة.
- **اهتزاز ونقرة صوت** قابلان للتحكم، ووضع معاينة لتجربة الواجهة على هواتف بلا IR.
- واجهة **عربية RTL** كاملة، تصميم داكن فخم (أسود + ذهبي)، وخط Tajawal.

## البروتوكولات المدعومة

`NEC` · `NECext` · `Samsung32` · `Sony SIRC / SIRC15 / SIRC20` · `RC5 / RC5X` · `RC6` · `RCA` ·
`Kaseikyo (Panasonic)` — مع إرسال الموجة الحاملة على ٣٦/٣٨/٤٠ كيلوهرتز حسب البروتوكول،
وتكرار تلقائي مناسب لكل بروتوكول.

## المتطلبات

- هاتف أندرويد 7.0 فأعلى (minSdk 24).
- **مُرسِل IR** للعمل الفعلي (شاومي/ريدمي، هواوي/هونر، سامسونج القديمة، إل جي G-series، HTC…).
  بدون مُرسِل يعمل التطبيق بوضع المعاينة.

## البناء

```bash
cd shuaa-remote
./gradlew assembleDebug
# الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
```

أو افتح مجلد `shuaa-remote` في Android Studio (AGP 8.7 / Kotlin 2.0 / JDK 17).

### بناء تلقائي على GitHub

كل دفعة إلى `shuaa-remote/` تشغّل سير عمل `Build شُعاع APK` وتنتج ملف APK قابلاً للتنزيل من
تبويب **Actions → آخر تشغيل → Artifacts**.

## بنية المشروع

```
app/src/main/java/com/shuaa/remote/
├── MainActivity.kt            # التنقل بين الشاشات
├── ShuaaViewModel.kt          # حالة التطبيق والإرسال
├── ShuaaTileService.kt        # بلاطة الإعدادات السريعة
├── data/                      # النماذج، مكتبة الأكواد، التخزين
├── ir/                        # مُرمِّز البروتوكولات والمُرسِل + تحليل الكاميرا
└── ui/                        # الشاشات والمكوّنات والثيم
tools/build_codes.py           # مولّد مكتبة الأكواد من Flipper-IRDB
app/src/main/assets/codes.json # مكتبة الأكواد المدمجة
```

## توليد مكتبة الأكواد

```bash
python3 tools/build_codes.py /path/to/Flipper-IRDB/TVs app/src/main/assets/codes.json
```
